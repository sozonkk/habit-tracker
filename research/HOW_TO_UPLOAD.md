# Jak wrzucić inspiracje do projektu

## Opcja 1: Przez git (z komputera)

```bash
# 1. Wejdź do folderu projektu
cd habit-tracker

# 2. Wrzuć pliki do odpowiednich folderów:
#    - Screenshoty → research/screenshots/
#    - Linki/opisy → research/inspiration/

# 3. Dodaj do gita
git add research/
git commit -m "Add workout app inspirations"
git push
```

## Opcja 2: Przez GitHub web interface

1. Wejdź na GitHub do tego repozytorium
2. Przejdź do folderu `research/screenshots/`
3. Kliknij "Add file" → "Upload files"
4. Przeciągnij screenshoty
5. Commit changes

## Opcja 3: Wyślij mi linki/screenshoty w czacie

Możesz też po prostu wkleić:
- Linki do aplikacji
- Screenshoty bezpośrednio w czacie
- Opisy tego, co Ci się podoba

A ja to wszystko zorganizuję i przeanalizujemy razem!

## Co warto zawrzeć w analizie?

✅ Nazwa aplikacji/link
✅ Co Ci się podoba? (konkretne funkcje)
✅ Co można poprawić?
✅ Screenshot najważniejszych ekranów
